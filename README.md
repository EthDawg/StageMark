# StageMark archive

StageMark is now part of **[Workbench](https://github.com/EthDawg/workbench)**. Workbench is the single active project for Mac, iPhone and iPad; all new development starts from its `main` branch.

- [Get Workbench and read the guide](https://workbench-mac.vercel.app)
- [Contribute to Workbench](https://github.com/EthDawg/workbench/blob/main/CONTRIBUTING.md)
- [Report an issue or find current work](https://github.com/EthDawg/workbench/issues)

This repository is retained as a read-only archive of the original standalone Mac app, its MIT-licensed source, releases and contribution history. Existing release tags and assets remain available as historical downloads. They are not the current Workbench build.

StageMark's presentation and drawing code, including the presenter preview polish, was imported into Workbench's `StageKit` module. [Source provenance](https://github.com/EthDawg/workbench/blob/main/docs/consolidation-source.md) records the original revisions and preservation. Do not maintain parallel feature implementations here.

The original README and contributor instructions remain in Git history and release tags. Archiving the source does not delete installed apps or user data.
