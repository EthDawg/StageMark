# Contributing

All new contributions belong in **[EthDawg/workbench](https://github.com/EthDawg/workbench)**, based on `main`.

Follow the [Workbench contributor guide](https://github.com/EthDawg/workbench/blob/main/CONTRIBUTING.md) for setup, code entry points, tests and PRs. Use [Workbench issues](https://github.com/EthDawg/workbench/issues) as the single work queue.

StageMark is a historical archive. Its source, releases, notices and Git history remain available for provenance; no separate feature or maintenance stream continues here.
